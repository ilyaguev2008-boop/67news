# Football News Bot

Бот проверяет футбольные источники (RSS, чужие Telegram-каналы, Instagram),
формирует черновики новостей (текст + фото) и присылает их тебе в личку с
кнопками **Одобрить / Редактировать / Отклонить**. При одобрении новость
публикуется в выбранный тобой канал.

## 1. Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Настройка

1. Скопируй `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Заполни `.env`:
   - `BOT_TOKEN` — получи у [@BotFather](https://t.me/BotFather)
   - `ADMIN_ID` — твой Telegram user_id (узнать можно у [@userinfobot](https://t.me/userinfobot))
   - `UNSPLASH_ACCESS_KEY` — необязательно, запасной вариант поиска фото
3. Список источников (`FEEDS`) уже заполнен в `config.py` — 22 проверенных
   RSS-ленты (BBC Sport по клубам + общие ленты BBC/Sky/Guardian).

## 3. Запуск

```bash
python bot.py
```

## Как это работает

При `/start` бот показывает две кнопки:

- **📋 Мои каналы** — управление списком каналов, куда бот может публиковать.
- **🔄 Проверить ленту новостей** — проверяет все источники и присылает
  новости по одной: текст (переведённый) + фото + кнопка **🔗 Источник** +
  кнопки модерации.

## Как бот собирает текст новости

Извлечение текста статьи использует `readability-lxml` (та же идея, что
"режим чтения" в браузере) — она умеет отличать основной текст статьи от
меню, рекламы, подписок и related-блоков лучше, чем простой перебор всех
`<p>` на странице. Если библиотека недоступна или не справилась — есть
запасной способ (поиск внутри `<article>`, с фильтром явного мусора по
ключевым словам вроде "sign up", "subscribe", "read more" и т.п.).

Текст переводится **целиком**, с сохранением разбивки на абзацы, и
обрезается под лимит длины (`ARTICLE_MAX_CHARS`) только **после**
перевода, по границе абзаца — а не как раньше, когда обрезка происходила
на середине обработки и текст мог обрываться посреди предложения ещё до
перевода.

Формат поста: обычные новости — заголовок + абзацы текста; посты с прямой
речью (иконка 🗣) — заголовок + текст в кавычках-«ёлочках», как цитата.

## Как бот подбирает фото (алгоритм)

1. **Читает и анализирует пост** — заголовок и текст статьи, на английском,
   до перевода.
2. **Разбирает футболистов и клубы**, упомянутых в тексте — клубы по
   списку из `config.FEEDS`, игроков — по паттерну "Имя Фамилия".
3. **Ищет фото исходя из этого разбора**, по приоритету:
   - если найден конкретный футболист — сначала точный портрет из его
     статьи в **Wikipedia** (pageimage — фото из карточки статьи, самый
     точный источник для конкретного человека);
   - если там не нашлось — полнотекстовый поиск по файлам **Wikimedia
     Commons** (по игроку+клубу или просто клубу);
   - если и там пусто — **Unsplash** (если задан `UNSPLASH_ACCESS_KEY`);
   - если по точному запросу вообще ничего не нашлось — те же источники
     повторно с более общим запросом (клуб или просто "football");
4. **Скачивает и проверяет найденное фото** (`download_and_prepare_image`)
   — не просто передаёт ссылку в Telegram, а сам скачивает файл,
   проверяет, что это реально изображение, и конвертирует в JPEG (через
   Pillow) перед отправкой. Так исключаются типичные проблемы: сайт
   отдал HTML вместо картинки, формат WebP/AVIF без поддержки, редирект,
   требование cookies и т.п.
5. Если скачать/проверить не удалось (или вообще ничего не нашлось) —
   локальный файл-заглушка `media/placeholder.jpg`, гарантированно
   прикрепляется, не ссылка в интернете.
6. Фото со страницы источника (BBC/Sky и т.п.) и логотипы/иконки/газетные
   вырезки намеренно исключены — там почти всегда чужой заголовок или
   вотермарка издания.

## Настройки в config.py

- `POLL_INTERVAL_MINUTES` — как часто фоново проверять источники
- `LOOKBACK_HOURS` — за какой период считать новости актуальными
- `ARTICLE_MAX_CHARS` — макс. длина текста поста после перевода (380 по умолчанию)
- `USE_SOURCE_IMAGES` — вернуть старое поведение (фото со страницы
  источника, с вотермаркой)

## Дополнительные источники (необязательно)

### Чужие Telegram-каналы
Через юзербот (Telethon) — см. `TELEGRAM_API_ID`/`TELEGRAM_API_HASH`/
`TELEGRAM_PHONE` в `.env` и `TELEGRAM_CHANNELS_TO_MONITOR` в `config.py`.
Ключи получить на [my.telegram.org](https://my.telegram.org).

### Instagram (⚠️ нестабильно)
Через `instaloader` — может в любой момент перестать работать без
предупреждения (у Instagram нет официального API для чтения чужих
аккаунтов). `INSTAGRAM_ACCOUNTS_TO_MONITOR` в `config.py`.
