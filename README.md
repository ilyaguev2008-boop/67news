# Football News Bot

Бот проверяет RSS-ленты футбольных сайтов, формирует черновики новостей
(текст + фото) и присылает их тебе в личку с кнопками
**Одобрить / Редактировать / Отклонить**. При одобрении новость публикуется
в твой канал.

## 1. Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Настройка

1. Скопируй `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Заполни `.env`:
   - `BOT_TOKEN` — получи у [@BotFather](https://t.me/BotFather)
   - `ADMIN_ID` — твой Telegram user_id (узнать можно у [@userinfobot](https://t.me/userinfobot))
   - `CHANNEL_ID` — username канала (`@channel`) или числовой ID (`-100...`).
     Бот должен быть добавлен в канал **администратором** с правом публикации.
   - `UNSPLASH_ACCESS_KEY` — необязательно. Если оставить пустым, при
     отсутствии картинки в статье бот подставит фото-плейсхолдер вместо
     поиска по теме.
3. Открой `config.py` и заполни список `FEEDS` — RSS-ссылки твоих 10 сайтов:
   ```python
   FEEDS = [
       ("Sport.ru", "https://sport.ru/rss/football.xml"),
       ("Championat", "https://www.championat.com/rss/news/football/"),
       # ...
   ]
   ```
   Если у сайта нет открытой RSS-ленты — её нужно найти (обычно `/rss`,
   `/feed`, `/rss.xml`) либо заменить на другой источник, у которого она есть.
   Текущая версия бота работает только с RSS (как договорились); парсинг
   HTML-страниц без RSS — отдельная доработка, дай знать, если понадобится.

## 3. Запуск

```bash
python bot.py
```

Бот сразу начнёт проверять ленты каждые `POLL_INTERVAL_MINUTES` (по
умолчанию 10 минут, настраивается в `config.py`). Команда `/check` в чате с
ботом запускает проверку немедленно, не дожидаясь таймера.

## Как это работает

При `/start` бот показывает две кнопки:

- **📋 Мои каналы** — управление списком каналов, куда бот может публиковать.
  Добавить канал можно тремя способами: переслать боту любое сообщение из
  канала, прислать его `@username`, или числовой ID. Бот должен быть
  добавлен в канал администратором с правом публикации. Нажатие на канал
  в списке удаляет его.

- **🔄 Проверить ленту новостей** — запускает проверку всех `FEEDS` и
  присылает новые новости **по одной**: текст (переведённый на русский) +
  фото + кнопки **Одобрить / Редактировать / Отклонить**. После действия
  над одной новостью бот сразу присылает следующую из этой проверки — не
  нужно запускать команду заново.

  При нажатии **Одобрить**: если каналов больше одного — бот спросит, в
  какой из них публиковать (кнопки с названиями каналов). Если канал
  всего один — публикует сразу в него.

Фоновый планировщик (`APScheduler`) сам проверяет ленты каждые
`POLL_INTERVAL_MINUTES` и копит новые черновики в базе — но не спамит тебя
уведомлениями; чтобы их увидеть, нажми **🔄 Проверить ленту новостей**.

## Возможные доработки (по запросу)

- Поддержка сайтов без RSS (парсинг HTML напрямую).
- Возможность заменить фото вручную (прислать своё).
- Публикация одной новости сразу в несколько каналов за раз (сейчас — один канал за одно одобрение).
- Более качественный перевод (DeepL или через LLM вместо бесплатного Google Translate).
