# Football News Bot

Бот проверяет футбольные источники (RSS, чужие Telegram-каналы, Instagram),
формирует черновики новостей (текст + фото) и присылает их тебе в личку с
кнопками **Одобрить / Редактировать / Отклонить**. При одобрении новость
публикуется в выбранный тобой канал.

## 1. Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Настройка

1. Скопируй `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Заполни `.env`:
   - `BOT_TOKEN` — получи у [@BotFather](https://t.me/BotFather)
   - `ADMIN_ID` — твой Telegram user_id (узнать можно у [@userinfobot](https://t.me/userinfobot))
   - `UNSPLASH_ACCESS_KEY` — необязательно. Если оставить пустым, при
     отсутствии картинки в статье бот подставит фото-плейсхолдер вместо
     поиска по теме.
3. Список источников (`FEEDS`) уже заполнен в `config.py` — 23 проверенных
   RSS-ленты (BBC Sport по клубам + общие ленты BBC/Sky/Guardian). Можно
   менять при желании.

## 3. Запуск

```bash
python bot.py
```

Бот сразу начнёт проверять источники каждые `POLL_INTERVAL_MINUTES` (по
умолчанию 1 минута, настраивается в `config.py`).

## Как это работает

При `/start` бот показывает две кнопки:

- **📋 Мои каналы** — управление списком каналов, куда бот может публиковать.
  Добавить канал можно тремя способами: переслать боту любое сообщение из
  канала, прислать его `@username`, или числовой ID. Бот должен быть
  добавлен в канал администратором с правом публикации. Нажатие на канал
  в списке удаляет его.

- **🔄 Проверить ленту новостей** — запускает проверку всех источников и
  присылает новости **по одной**: текст (переведённый на русский) + фото +
  кнопка **🔗 Источник** + кнопки **Одобрить / Редактировать / Отклонить**.
  Показывает **все** накопленные непросмотренные новости — включая то, что
  фоновый планировщик нашёл, пока ты не открывал бота, а не только
  найденное в этот момент.

  При нажатии **Одобрить**: если каналов больше одного — бот спросит, в
  какой из них публиковать. Если канал всего один — публикует сразу в него.

Фоновый планировщик (`APScheduler`) сам проверяет источники каждые
`POLL_INTERVAL_MINUTES` и копит новые черновики в базе.

## Настройки в config.py

- `POLL_INTERVAL_MINUTES` — как часто фоново проверять источники (в минутах)
- `LOOKBACK_HOURS` — за какой период считать новости актуальными
- `ARTICLE_MAX_CHARS` — макс. длина текста статьи, который бот берёт со страницы (700 по умолчанию)
- `MAX_ENTRIES_PER_FEED` — верхняя граница записей с одной RSS-ленты за проход

## Дополнительные источники (необязательно)

### Чужие Telegram-каналы

Работает через твой личный Telegram-аккаунт (юзербот, библиотека Telethon) —
только так можно читать чужие каналы, не будучи их админом.

1. Зайди на [my.telegram.org](https://my.telegram.org), залогинься своим
   номером телефона, создай приложение — получишь `api_id` и `api_hash`.
2. В `.env` впиши:
   ```
   TELEGRAM_API_ID=твой_api_id
   TELEGRAM_API_HASH=твой_api_hash
   TELEGRAM_PHONE=+79991234567
   ```
3. В `config.py` заполни `TELEGRAM_CHANNELS_TO_MONITOR` — username каналов
   без `@`:
   ```python
   TELEGRAM_CHANNELS_TO_MONITOR = ["fabrizioromano", "someclub_channel"]
   ```
4. При первом запуске бот попросит в консоли PyCharm ввести код
   подтверждения (придёт тебе в Telegram) и, если включена
   двухфакторная аутентификация — пароль. После этого создастся файл
   сессии (`userbot_session.session`) — повторно логиниться не придётся.

Новые посты из этих каналов появляются в общем списке черновиков так же,
как RSS-новости — увидишь их через **🔄 Проверить ленту новостей**.

### Instagram (⚠️ нестабильно)

У Instagram нет официального публичного API для чтения чужих аккаунтов.
Бот использует `instaloader`, который эмулирует браузер — это может
**в любой момент перестать работать без предупреждения**: Instagram умеет
требовать логин, показывать капчу или банить IP при частых запросах. Если
источник вдруг замолчит — это ограничение самого Instagram, а не баг бота.

В `config.py` заполни `INSTAGRAM_ACCOUNTS_TO_MONITOR` — username аккаунтов
без `@`:
```python
INSTAGRAM_ACCOUNTS_TO_MONITOR = ["realmadrid", "fcbarcelona"]
```
Никаких дополнительных ключей не нужно — но именно поэтому это наименее
надёжный из всех источников бота.

## Возможные доработки (по запросу)

- Возможность заменить фото вручную (прислать своё).
- Публикация одной новости сразу в несколько каналов за раз (сейчас — один канал за одно одобрение).
- Более качественный перевод (DeepL или через LLM вместо бесплатного Google Translate).
- Логин в Instagram (снижает риск капчи/блокировки, но добавляет риск бана самого аккаунта, если Instagram сочтёт активность подозрительной).
